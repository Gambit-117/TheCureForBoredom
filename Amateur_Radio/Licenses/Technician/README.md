# FCC Technician License
The FCC Technician Class license is the entry-level amateur (ham) radio license. It requires passing a 35-question multiple-choice exam covering basic regulations, operating practices, and electronics theory, with no Morse code requirement. 

With a Technician Class license, you wil have all ham radio privileges above 30 MHz. These privileges include the 2-meter band, FM voice, digital packet transmission, single-sideband, and more. Techs may also use the 80, 40, and 15 meter bands using CW, and the 10 meter band using CW, voice, and digital.

Before you can get on the air, you need to be licensed and know the rules to operate legally. US licenses are good for 10 years before renewal and anyone may hold one except a representative of a foreign government.
